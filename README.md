<h1 style="text-align: center;">Fun Messages!</h1><h2 style="text-align: center;">Customizable messages displayed at a set interval!</h2><p style="text-align: left;">A simple and fun way to entertain your users with random messages. Easily customizable with a single txt file for the messages and some JSON for the interval.</p><p style="text-align: left;">Inspired by [Minecraft Indev+](https://legacy-plus.dejvoss.cz/)'s FunMessages.txt implementation for multiplayer.</p>

***

 <h2 style="text-align: center;">Requirements</h2>     

*   [Serilum's Hybrid (Curseforge)](https://www.curseforge.com/hytale/mods/hybrid)
*   [Zoltus' TinyMsg (Github)](https://github.com/Zoltus/TinyMessage/)

***

<h2 style="text-align: center;">Usage</h2>

Files are located at **\[HytaleUserData\]/saves/\[YourSaveName\]/mods/xyz.starrymic\_FunMessages**

*   FunMessages.txt - Holds messages
*   funmessages.config.json - Stores the message interval

**/refreshfunmessages** - Reloads all messages from FunMessages.txt
